# Thoughts для iPhone — экраны и пути

Статус: **согласовано** 2026-10-15. Функции и решения (Р1–Р10) —
[SPEC.md](SPEC.md), компоненты — [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md).
Ссылки «Р…» — на решения в SPEC.md §6.

Устройство: только iPhone, портрет. Язык интерфейса — английский (как на Mac).

---

## Карта экранов

```
Онбординг (S9) ──► Лента Space (S1) ──тап по карточке──► Редактор (S2)
                     │  ├─ меню Space (S6) ─► Переименовать (S5)
                     │  ├─ защищённый Space ─► Экран блокировки (S3)
                     │  └─ Lock-карточка ─► Face ID / код (S4)
                     └─ Settings (S7) ─► Код: задать / сменить (S8)
Выбор при первом синке (S10) — из S9 или S7, когда данные есть с обеих сторон
Подтверждение удаления (S11) — из S1 (свайп, меню S12) и S2
Меню карточки (S12) — долгое нажатие в S1
```

---

## S1. Лента Space

Главный экран. Space = чат, карточка = сообщение.

**Содержимое**
- **Вкладки Spaces** сверху, свайп по ленте влево/вправо переключает Space
  (как папки в Telegram). По умолчанию — все 9; скрытые в Settings → Spaces
  не показываются (Р3).
- **Кнопки навбара:** Settings (S7); меню текущего Space (S6).
- **Лента карточек.** Каждая карточка — отдельный блок. Свежие (по
  `contentModifiedAt`) — внизу, у поля ввода; карточки без даты — в порядке
  холста Mac (сверху вниз, слева направо). Лента не перестраивается под
  пальцем: новый порядок применяется при открытии Space и при возврате из
  редактора, с анимацией.
- **Превью карточки:** минимум ~2 строки, максимум ~8–10 с затуханием;
  Markdown отрисован (заголовки, списки, задачи, цитаты, код, выделения).
  Тег — точка в углу. Spoiler — звёздный блюр в тех же пределах, тап
  открывает. Lock — минимальная высота и замок, тап → S4.
- **Поле ввода** внизу: только текст, без «+» и микрофона. Отправка создаёт
  карточку в текущем Space и прокручивает ленту к ней.
- **Строка проблемы синка** (только если синк включён и есть проблема): над
  полем ввода или под вкладками — «Offline», «Sign in to iCloud», «Couldn’t
  sync». Тап → S7.

**Действия:** тап по карточке → S2; свайп влево → Delete (S11); долгое
нажатие → меню S12 (Copy, Share, Delete) (Р5, Р8); тап по задаче `- [ ]` в
превью → отметить, порядок ленты не меняется до следующего открытия Space
(Р4); тап по ссылке → открыть.

**Состояния**

| Состояние | Что видно |
|---|---|
| Пустой Space | подсказка над полем ввода: «Type a thought below» |
| Первая загрузка из iCloud | лента пустая, индикатор «Syncing…» вместо подсказки |
| Обычный | карточки разной длины: 1 строка, 2–10 строк, длинная с затуханием |
| Карточка с тегом | точка цвета тега в углу |
| Spoiler | звёздный блюр; после тапа — текст, снова скрывается через 5 с после ухода с карточки (как на Mac) |
| Lock | замок, минимальная высота; после первого Face ID в сессии — все Lock-карточки открываются тапом, до ухода в фон / Auto-Lock (Р7) |
| Защищённый Space закрыт | вместо ленты и поля — S3 |
| Офлайн / нет аккаунта / ошибка синка | лента работает, строка проблемы |
| Синк выключен | никакой строки: локальный режим — норма |
| Клавиатура открыта | поле ввода над клавиатурой, лента сжимается, последняя карточка видна |
| Длинный ввод | поле растёт до ~5 строк, дальше прокрутка внутри |

## S2. Редактор карточки

Полноэкранный, открывается тапом по карточке.

**Содержимое**
- **Навбар:** назад (сохранение автоматическое); точка тега → выбор из 7
  цветов + «без тега»; переключатели **Spoiler** и **Lock**; меню «…»:
  **Copy**, **Share**, **Delete** (S11) (Р5, Р8).
- **Текст** — весь, с Markdown-отрисовкой; символы разметки видны в строке
  под курсором и прячутся в остальных (как на Mac).
- **Панель Markdown над клавиатурой:** Bold, Italic, Strikethrough,
  Highlight, Heading, Bullet, Task, Quote, Code, Link; повторное нажатие
  снимает формат.

**Состояния**

| Состояние | Что видно |
|---|---|
| Просмотр (клавиатура скрыта) | текст, тап в текст ставит курсор |
| Правка | клавиатура + панель Markdown |
| Правка пришла с Mac, пока открыт редактор | текст не меняется под курсором; применится после выхода (`BoardModel.editingCardID`) |
| Карточку удалили на Mac, пока открыт редактор | правка побеждает удаление: карточка остаётся и вернётся на Mac (без UI) |
| Тег / Spoiler / Lock включены | состояние переключателей в навбаре |
| Пустой текст при выходе | карточка удаляется, с синком — и на Mac (Р10) |

## S3. Экран блокировки Space

Вместо ленты защищённого Space.

- Замок, имя Space, «Unlock with Face ID» (если включено) и цифровая
  клавиатура кода.
- Неверный код — встряхивание точек.
- Fail-closed: если Space защищён, а кода на iPhone ещё нет (синк включён,
  код не доехал из iCloud Keychain) — «Waiting for your passcode from iCloud»;
  содержимое не показывается.

**Состояния:** Face ID предложен автоматически при открытии Space; Face ID
выключен — только клавиатура; кода нет (fail-closed); ввод неверный.

## S4. Открыть Lock-карточку

Системный Face ID; при отказе — клавиатура кода из S3 в шторке. Один раз на
сессию: дальше Lock-карточки открываются тапом, пока приложение не ушло в
фон и не сработал Auto-Lock (Р7).

## S5. Переименовать Space

Алерт с полем: текущее имя, до 30 символов; пустое → имя по умолчанию
«Space N».

## S6. Меню Space

Из навбара S1: **Rename…** (S5), **Lock Space** (если Space Lock включён в
Settings; сразу закрывает текущий Space) / **Turn Off Lock for This Space**.

## S7. Settings

Список-группы, системный вид iOS.

| Секция | Содержимое |
|---|---|
| iCloud | тумблер **Sync with iCloud**; статус (`CloudSyncStatus.text`); **Sync Now** / **Try Again**; пояснение «Your Mac and iPhone share the same Thoughts» |
| Space Lock | тумблер **Passcode** → S8; **Change Passcode…**; **Use Face ID**; **Auto-Lock** (Never … 1 hour + при уходе в фон); список Spaces с тумблерами защиты |
| Spaces | список 9 Spaces с тумблерами «показывать во вкладках»; **Hide Empty Spaces** — скрыть все пустые одной кнопкой; **Show All** — вернуть (Р3). Настройка этого iPhone |
| Appearance | **Theme**: Auto / Light / Dark; **Text Size**: Dynamic Type по умолчанию или S / M / L / XL (Р9) |
| About | версия; Replay Onboarding; GitHub, Telegram Channel, Email; намёк «Thoughts for Mac» со ссылкой на App Store |

**Состояния:** синк выключен / включается / Up to date / Offline / нет
аккаунта / ошибка; Space Lock выключен (секция свёрнута до тумблера);
текущий Space закрыт — Settings открываются, но список защищённых Spaces и
выключение кода требуют разблокировки (как на Mac: «Unlock the current Space
to access Settings» — уточнить для iPhone).

## S8. Код: задать / сменить

Два шага: ввести 4 цифры → повторить. При смене — сначала текущий код.
С синком код уходит в iCloud Keychain (на Mac код — 4 любые клавиши;
совместимость кодов Mac → iPhone — уточнить при сборке).

## S9. Онбординг

Короткий, 3–4 экрана, пропускается.

1. **Welcome** — «Your thoughts, one tap away»: лента и поле ввода.
2. **Spaces** — вкладки и свайп; теги, Spoiler, Lock в карточке.
3. **Private** — Space Lock и Lock карточки (Face ID).
4. **Sync** — «Thoughts is best with your Mac»: Sync with iCloud / Not Now
   (Р1). Если в iCloud уже есть доска — после включения она появится сама.

## S10. Выбор при первом синке

Системный алерт, когда данные есть и на iPhone, и в iCloud:
«Your Thoughts are already in iCloud» — **Merge** / **Use iCloud** /
**Use This iPhone**. Перед выбором — автобэкап (`AutomaticBackups`).

## S11. Подтверждение удаления

Action sheet: «Delete Card» (деструктивное) / Cancel. Для Lock-карточки —
сначала S4.

## S12. Меню карточки (долгое нажатие)

Системное контекстное меню с превью карточки: **Copy** (текст в буфер),
**Share** (системный лист, текст карточки), **Delete** (S11). Для закрытой
Lock-карточки — сначала S4.

## Пользовательские пути

Каждый путь проходится без Mac и с выключенным синком, если не сказано
иное.

**П1. Первый запуск без Mac.** S9 (1→4) → «Not Now» → S1, Space 1 пустой →
набрать в поле → отправить → карточка внизу ленты.

**П2. Первый запуск, доска уже в iCloud (есть Mac).** S9 → «Sync with
iCloud» → S1 «Syncing…» → доска появляется; Spaces и названия как на Mac.

**П3. Включить синк позже, на iPhone уже есть заметки.** S7 → Sync with
iCloud → если в iCloud пусто — всё уходит туда молча; если есть — S10.

**П4. Выключить синк.** S7 → тумблер off → данные остаются на iPhone, в
iCloud ничего не удаляется.

**П5. Быстро записать мысль.** Открыть приложение → открывается последний
Space, поле ввода внизу → набрать → отправить. Цель — без единого лишнего
тапа, кроме фокуса на поле.

**П6. Переключить Space и найти карточку.** Свайп по ленте / тап по вкладке
→ прокрутка вверх к старым → тап → S2. (Поиск по тексту — позже.)

**П7. Отредактировать карточку.** S1 → тап → S2 → правка с панелью Markdown
→ назад → лента перестраивается: карточка внизу (свежая правка).

**П8. Тег, Spoiler, Lock.** S2 → точка тега → цвет; Spoiler / Lock в
навбаре → назад → в ленте точка, блюр или замок.

**П9. Удалить карточку.** S1 свайп, S1 долгое нажатие (S12) или S2 «…» →
Delete → S11 → карточка исчезает (с синком — и на Mac).

**П10. Переименовать Space.** S1 → меню Space (S6) → Rename… → S5.

**П11. Защитить Space.** S7 → Passcode → S8 (задать код) → включить защиту
Space (в S7 или S6 → Lock Space) → Space закрыт (S3) → Face ID или код →
лента. Auto-Lock и уход в фон снова закрывают Space.

**П12. Открыть Lock-карточку.** S1 → тап по замку → S4 → текст; через 5 с
после ухода с карточки снова закрыта.

**П13. Правка на Mac, пока карточка открыта на iPhone** (синк включён). S2
открыт → на Mac правят ту же карточку → текст на iPhone не меняется → назад
→ правка с Mac применилась (слияние по полям; при конфликте текста
побеждает более новая).

**П14. Пропал интернет / вышли из iCloud** (синк включён). S1 работает как
обычно, строка «Offline» / «Sign in to iCloud»; правки копятся и уходят,
когда связь вернулась.

**П15. Убрать лишние Spaces из вкладок.** S7 → Spaces → Hide Empty Spaces →
во вкладках только Spaces с карточками; вернуть — Show All или тумблер
отдельного Space.

**П16. Отметить пункт списка покупок.** S1 → тап по `- [ ]` в превью →
галочка; карточка остаётся на месте до следующего открытия Space.

**П17. Поделиться карточкой.** S1 долгое нажатие (S12) или S2 «…» → Share →
системный лист (Messages, Mail, …) или Copy.
