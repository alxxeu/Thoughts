# Thoughts для iPhone — продукт и функции

Статус: **черновик спецификации** (2026-10-15). Экраны и пути —
[SCREENS.md](SCREENS.md), дизайн-система — [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md).
Порядок работы: спецификация → дизайн в Figma → сборка.

---

## 1. Роль

**Thoughts для iPhone — самостоятельные заметки, которые становятся лучше
вместе с Mac.**

- Без Mac и без iCloud приложение — полноценные заметки: Spaces, карточки,
  теги, Spoiler/Lock, Space Lock. Всё хранится на iPhone.
- С синком iCloud iPhone показывает ту же доску, что Mac, и правит её: Mac —
  стол, где мысли раскладывают на холсте; iPhone — карман, где их быстро
  записывают и подсматривают.
- Онбординг работает без Mac, но намекает: лучший опыт — вместе с Thoughts
  на Mac.

## 2. Принципы

1. **Записать за секунды.** Открыл → поле ввода уже внизу → набрал → отправил.
   Как сообщение в чат.
2. **Подсмотреть без усилий.** Лента карточек Space, свежие внизу, у поля.
3. **Необходимый минимум.** На iPhone только то, без чего заметки не
   работают. Остальное — «позже» (§4) или остаётся Mac.
4. **Не ломать Mac.** iPhone не трогает геометрию карточек на холсте Mac и
   не переставляет их.
5. **Тот же язык, что на Mac.** Теги, Spoiler, Lock, Space Lock, Markdown —
   те же понятия и цвета; новое придумываем только там, где у телефона
   другой способ взаимодействия.

## 3. Модель, которая уже общая

Из `Shared/` (собирается и для Mac, и для iOS):

| Сущность | Что есть |
|---|---|
| Space (`Workspace`) | 9 слотов, имя (до 30 символов), `isProtected` (Space Lock) |
| Карточка (`Card`) | текст в Markdown, тег (7 цветов `CardTagColor`), приватность (`CardPrivacyMode`: none / spoiler / lock), `isAIGenerated`, даты правки текста / геометрии / мета |
| Markdown (`MarkdownStyler`) | блоки: заголовок, маркированный и нумерованный список, задача `- [ ]`, цитата, код, разделитель; в строке: жирный, курсив, зачёркнутый, подчёркнутый `~`, выделение, код, ссылка |
| Синк (`CloudSyncEngine`) | iCloud (CKSyncEngine), слияние по группам полей, правка побеждает удаление |
| Хранение (`BoardStore`, `BoardModel`) | board.json на устройстве; работает без сети и без синка |

Геометрия карточек (позиция, размер, z-порядок) хранится и синкается, но на
iPhone не показывается и не меняется.

## 4. Инвентарь Mac → iPhone

Решения: **оставить** — как на Mac; **адаптировать** — та же функция, другой
способ; **убрать** — на iPhone не нужна; **позже** — нужна, но не в первой
версии. Критерий «оставить» — необходимый минимум для заметок на iPhone.

### Доска и карточки

| Функция | На Mac | iPhone | Почему / как |
|---|---|---|---|
| Spaces 1–9 | меню Spaces, ⌥1–9 | **адаптировать** | вкладки сверху, свайп между ними (как папки в Telegram) |
| Переименовать Space | клик по имени в тулбаре | **оставить** | без Mac больше негде |
| Создать карточку | драг по холсту | **адаптировать** | поле ввода внизу ленты; карточка = сообщение |
| Править текст | клик по карточке | **адаптировать** | тап → редактор карточки на весь экран |
| Удалить карточку | долгое нажатие на крестик | **адаптировать** | в редакторе и/или свайпом в ленте (открытый вопрос В5) |
| Двигать, менять размер | драг, угол | **убрать** | на iPhone нет холста |
| Z-порядок, Focus Card (⌘F) | клик поднимает, ⌘F | **убрать** | порядок ленты — по дате правки; редактор и так на весь экран |
| Tidy Cards | тулбар | **убрать** | раскладка холста |
| Clear Space | меню File, тулбар | **убрать** | опасно и редко; удаление по одной |
| Quick Capture (глобальный хоткей, панель) | ⌃⌥⌘N, панель поверх приложений | **адаптировать** | поле ввода и есть быстрый захват; системные входы (виджет, Share, Action button) — позже |

### Текст и Markdown

| Функция | На Mac | iPhone | Почему / как |
|---|---|---|---|
| Markdown-отрисовка | `MarkdownRenderer` (AppKit) | **адаптировать** | тот же разбор `MarkdownStyler`, своя отрисовка на iOS |
| Форматирование ⌘B/⌘I/⌘U, ⇧⌘X, ⇧⌘H | меню Format | **адаптировать** | панель над клавиатурой в редакторе |
| Набор Markdown (`#`, `-`, `1.`, `[]`, `>`, `` ` ``, `---`) | символы прячутся вне строки | **оставить** | работает с любой клавиатуры; панель — подсказка |
| Галочки задач | клик по квадрату | **оставить** | в редакторе; в ленте — открытый вопрос В4 |
| Ссылки | клик открывает | **оставить** | тап в редакторе/превью |

### Теги и приватность

| Функция | На Mac | iPhone | Почему / как |
|---|---|---|---|
| Тег (7 цветов) | точка в углу → поповер, ⌃1–7, ⌃0 | **адаптировать** | меняется только в редакторе; в ленте — точка в углу |
| Spoiler | поповер точки; клик открывает | **адаптировать** | ставится в редакторе; в ленте — звёздный блюр, тап открывает |
| Lock карточки | поповер точки; Touch ID открывает | **адаптировать** | ставится в редакторе; в ленте — замок и минимальная высота; открытие — Face ID / код (В7) |

### Space Lock и безопасность

| Функция | На Mac | iPhone | Почему / как |
|---|---|---|---|
| Passcode (4 клавиши) | Settings → Security | **адаптировать** | свой код на iPhone (цифры); с синком — тот же, что на Mac, через iCloud Keychain |
| Touch ID | Settings → Security | **адаптировать** | Face ID / Touch ID iPhone |
| Auto-Lock (30 с … 1 ч, никогда) | Settings → Security | **оставить** | плюс блокировка при уходе приложения в фон |
| Lock Space (⌘L), список защищённых Spaces | меню View, Settings | **адаптировать** | действие в меню Space и в Settings → Security |
| Fail-closed при синке | защищённый Space закрыт, пока не пришёл код | **оставить** | то же правило |

### Синк и данные

| Функция | На Mac | iPhone | Почему / как |
|---|---|---|---|

| Автобэкапы перед импортом/синком | `AutomaticBackups` | **оставить** | работает само, UI нет |

## 5. Что меняет самостоятельность iOS

- **Синк — выбор.** Сейчас в коде синк на iPhone включён всегда
  (`ThoughtsiOS/ThoughtsiOSApp.swift`, `enableSyncIfNeeded`). Нужен тумблер
  и выбор при первом запуске — отдельный пункт сборки (BACKLOG-iOS.md).
- **Все действия — на iPhone.** Переименовать Space, удалить карточку,
  включить Space Lock и задать код — не требуют Mac.
- **Карточки с iPhone на холсте Mac.** Карточка, созданная на iPhone, —
  без позиции на холсте (у iPhone нет размера холста Mac). Где она окажется
  на Mac — В2.
- **Риск без бэкапа.** Без синка и без экспорта данные живут только на
  iPhone (резервная копия iOS их сохраняет). Экспорт — позже (В8).

## 6. Открытые вопросы

| # | Вопрос | Варианты | Предложение |
|---|---|---|---|
| В1 | Синк при первом запуске | спросить на экране онбординга · включить, если есть iCloud · выключить | спросить: «Sync with iCloud» / «Not Now», с намёком про Mac |
| В2 | Где на холсте Mac карточка с iPhone | Mac ставит в первое свободное место при получении (`firstFreeOrigin`) · каскадом у центра · отдельная «входящая» зона | первое свободное место активного размера окна, как Quick Capture |
| В3 | Spaces: всегда 9 вкладок | все 9 · только непустые и переименованные + «ещё» | непустые и переименованные; остальные — в меню |
| В4 | Галочка задачи в ленте | можно тапом в ленте · только в редакторе | в ленте можно: это быстрое действие, «правка» по продуктовым решениям |
| В5 | Удаление карточки | свайп в ленте · кнопка в редакторе · оба | оба; свайп с подтверждением для Lock |
| В6 | AI по карточке на iPhone | позже · сразу с Apple Intelligence (без ключей) | позже |
| В7 | Lock карточки: Face ID | на каждое открытие · на сессию до блокировки экрана | на каждое открытие (как Touch ID на Mac) |
| В8 | Экспорт без Mac | позже · минимальный Share карточки текстом | позже; Share текста карточки — кандидат в первую версию (дёшево) |
