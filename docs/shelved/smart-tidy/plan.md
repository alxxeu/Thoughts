# Tidy: умная расстановка (план)

## Context
Tidy Cards (`BoardViewModel.tidyCards`, BoardViewModel.swift:443) раскидывает карточки только по 4 углам по четвертям канвы. Нужна расстановка, которая работает сама и качественно: использует центр, группирует по смыслу, не двигает уже разложенное, откатывается. Пресетов нет. Ядро с геометрией — чистое и детерминированное; ИИ только решает, что с чем связано.

## Решения автора
1. База (без Apple Intelligence) переработана: геометрия использует и центр, не только углы.
2. «Умная» надстройка (Foundation Models) — тоггл в настройках ИИ (`AI/AISettings.swift`, `AI/AISettingsView.swift`), по умолчанию выкл.
3. spoiler/lock карточки: группируются только по тегу и положению; в эмбеддинги и модель не уходят.
4. Undo для Tidy.
5. Повторный Tidy на разложенном поле почти ничего не двигает.
6. 1–2 карточки: простое выравнивание, без ИИ. Мало карточек и групп <2: всё складывается по центру, не по углам.
7. Названия групп не показываем.

## Архитектура
Конвейер: **группы → блоки → размещение**. Новый файл `Thoughts/TidyLayout.swift` — чистые функции без `BoardViewModel`, чтобы тестировать.

1. **Группировка** (`TidyGrouping`), на выходе `[[UUID]]` (группа = упорядоченный список):
   - База: тег и близость на холсте (одинаковый тег — одна группа; без тега — кластеры по расстоянию центров). Заменяет «доминирующий угол».
   - Смысл (всегда доступен, не требует Apple Intelligence): `NLEmbedding` (NaturalLanguage) по тексту, агломеративная кластеризация; расстояние = смысл + тег + позиция. Только для карточек без privacy (`privacyMode == .none`).
   - Надстройка (если тоггл включён и `AppleIntelligenceAvailability.isAvailable`): `LanguageModelSession` + `@Generable` — группы и порядок внутри (шаги, очередь), вход — выжимки ~150 символов; при большом числе карточек сначала кластеры эмбеддингов, модели отдаются кластеры. Ошибка/недоступность/`exceededContextWindowSize` — тихий откат к базе (как в `AppleIntelligenceTextService`).
2. **Выравнивание размеров в группе** (до упаковки; `TidyLayout.normalizeSizes`). Размеры остаются на сетке `size(k) = k*cardSizeStep − cardGap`, минимум `minCardSize`:
   - Единый размер: если у большинства карточек группы один размер (например, минимальный квадрат), остальные подгоняются под него. Ширина и высота считаются независимо, выбирается мода по каждой оси.
   - Ровный блок: если группа разнородная, но 1–2 карточки отличаются от остальных на малый шаг (±1 плитка по ширине или высоте), их размер доводится до ближайшего размера ряда/колонки, чтобы блок вышел прямоугольным. Сильно отличающиеся карточки (больше ±1 плитки) не трогаем: это намеренно крупные или мелкие.
   - Не уменьшаем карточку, если текст перестанет в неё помещаться; в этом случае растим остальные или оставляем размер. Проверку «помещается» взять из существующей логики размера карточки (`BoardViewModel` ~стр. 138, округление к сетке) — уточнить при реализации.
   - Новые размеры пишутся через то же место, что и ресайз, и тоже входят в undo.
3. **Блоки**: каждая группа упаковывается существующими `computeShelfLayout`/`bestShelfLayout` (перенести без изменения логики) в компактный блок с размером.
3. **Размещение блоков** на канве (замена угловой схемы):
   - Групп <2 или карточек мало: один блок по центру канвы.
   - Иначе: **крупные блоки в углы, мелкие к центру**; зазор между группами больше `cardGap`; блок тянется к центроиду прежних позиций своих карточек (стабильность).
   - 1–2 карточки: центрирование/выравнивание в ряд, без группировки.
4. **Стабильность**: порядок групп и карточек детерминирован (по прежней позиции и id, не по случайности); якорь блока — прежний центроид; если после расчёта все сдвиги < порога (~cardGap/2), позиции не меняем. Тест: двойной Tidy = no-op.
5. **Undo**: `tidyCards` сохраняет позиции и размеры `[UUID: (CGPoint, CGSize)]` до раскладки в `BoardViewModel` (`tidyUndoSnapshot`); ⌘Z на уровне доски (когда фокус не в тексте карточки, там своя `UndoManager` в `CardTextView`) возвращает позиции. Проверить, нужен ли общий `UndoManager` окна или достаточно одного слота «последний Tidy»; по умолчанию — один слот, живёт до следующего изменения геометрии/текста. Анимация та же (spring).
6. **UI**: `SpaceToolbar.swift:268` вызывает `tidyCards`; пока модель думает — прогресс на иконке; кнопка неактивна при пустом Space (как сейчас). Тоггл — в `AISettingsView`.

## Этапы
1. `TidyLayout.swift` — выравнивание размеров, размещение блоков + упаковка (перенос из `BoardViewModel`), группировка по тегу/близости; `tidyCards` вызывает его. Тесты `ThoughtsTests/TidyLayoutTests.swift` (в Swift Testing, как остальные): 0/1/2 карточки, 1 группа → центр, 2+ группы, границы канвы и `topInset`, нет наложений, двойной Tidy = no-op, теги вместе, единый размер группы, подгонка 1–2 выбивающихся карточек, крупные блоки в углах, мелкие в центре.
2. Undo.
3. Эмбеддинги в группировке (privacy-фильтр, проверка на ru/en тексте).
4. Foundation Models + тоггл в настройках ИИ.
5. По каждому этапу: `BACKLOG.md` (раздел 4. Tidy), коммит. Правило 9: перед коммитом спросить про шаг онбординга/тип Tidy в `TipToastView.swift:39` и в шпаргалке.
