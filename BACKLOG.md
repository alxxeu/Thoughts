### Доска и карточки
- Канва с созданием карточки перетаскиванием; размер квантован шагом 60pt
  с зазором 16pt — колонка из нескольких карточек всегда точно совпадает
  по краю с одной крупной карточкой той же "тайловости"
- Драг/ресайз карточки с подсказками прилипания к краям/углам канвы и
  превью стыковки к соседним карточкам (edge hints, placement preview)
- Удаление карточки долгим нажатием (радиальный индикатор прогресса)
- Цветные теги (7 цветов) через попап у угла карточки
- Приватность карточки: `none` / `spoiler` (тап открывает, авто-скрытие
  через 5с после клика в сторону) / `lock` (открывается через Touch ID)
- Кастомный редактор на NSTextView: смарт-списки (`"- "`/`"1. "`),
  разделитель по `---`, персистентность форматирования (bold и т.п.)
  параллельно с обычным `text`, вставка только как plain text,
  контекстное меню с AI-подменю (см. AI ниже)
- Clear Space — очистка всех карточек текущего Space с подтверждением
  через alert (File-меню и кнопка в тулбаре)
- Постоянный AI-бейдж (иконка sparkle) на карточках, созданных через
  Ask AI/Summarize/Extract, с одноразовой pop-in анимацией "из-под нотча"

### Spaces
- 9 независимых Spaces, переключение через ⌥1–9, плашка с именем сверху
  канвы — клик открывает инлайн-переименование (лимит 30 символов)
- Персистентность через `BoardStore` (JSON в Application Support)
- Полностью раздельное состояние по каждому Space — переключение
  анимирует только уход старых карточек, новые появляются сразу

### Spotlight
- Индексация карточек в системный Spotlight (кроме spoiler/lock карточек)
- Переход по результату поиска: активация приложения, переключение на
  нужный Space, подсветка карточки — через
  `NSApplicationDelegate.application(_:continue:restorationHandler:)`,
  так как `.onContinueUserActivity` на SwiftUI-View для уже запущенного
  macOS-приложения ненадёжен

### Security / Space Lock
- Per-Space passcode lock — независимая блокировка каждого Space (не
  всего приложения)
- Cmd+L — заблокировать текущий Space немедленно
- "Manage Space Locks" в Settings — включение/выключение защиты по
  каждому Space отдельно
- Touch ID как опциональная надстройка поверх обязательного passcode
- Passcode — 4 физические клавиши (не только цифры), хранится в Keychain
  (не в UserDefaults/plaintext)
- Idle auto-lock с настраиваемым интервалом (Never / 30 сек / 1 / 5 / 10
  / 30 мин / 1 час)
- Settings недоступны из заблокированного Space (защита от обхода lock
  screen)
- Системные шорткаты пропускаются через passcode key capture, не
  блокируются им

### AI (Apple Intelligence)
- Единственный провайдер в этой сборке — Apple Intelligence, on-device
  через FoundationModels (macOS 26+), без API-ключа. Свои ключи
  ChatGPT/Claude — Pro-эксклюзив, в этой сборке кода нет вообще (ни
  HTTP-клиентов, ни Keychain-хранилища), а не просто скрыт в UI —
  `ENABLE_OUTGOING_NETWORK_CONNECTIONS = NO` в sandbox-энтайтлментах не
  даёт этой сборке обратиться к сети даже гипотетически
- Карточные AI-действия (правый клик → подменю AI): Summarize, Rewrite,
  Continue Writing (дописывает, не заменяет), Fix Grammar
- Ask AI для всего Space (иконка sparkle в тулбаре) — свободный вопрос с
  контекстом из всех непубличных карточек; там же Summarize Space и
  Extract Action Items
- Настраиваемая клавиша отправки в поле Ask AI (Return сразу /
  Shift+Return сразу)

### Focus Card (Cmd+F)
- Cmd+F центрирует карточку с текстовым фокусом в фиксированном размере
  640×480, остальные карточки гаснут и перестают кликаться, холст
  затемняется; no-op при заблокированном Space, в Desktop mode и во время
  онбординга
- `card.position`/`card.size` не меняются — фокус это чисто состояние
  отображения, ничего не персистится
- Выход: Cmd+F повторно, Escape, клик по затемнённому фону, смена Space.
  Подсказка про выход появляется над карточкой через 3 секунды
- В фокусе скрыты точка тега, AI-бейдж, кнопка удаления, ресайз-хендл и
  зона перетаскивания, а также верхняя капсула Space
- Панель Ask AI под карточкой: свободный запрос про эту карточку (через
  Apple Intelligence), ответ показывается под вопросом с разделителем и
  тремя действиями — Insert Below, Replace, Ask Again
- Подсказка "Try ⌘F to focus this card" — при печати в обычной карточке,
  после первого перехода длины текста через 60 символов; полупрозрачная,
  держится 4.5с, гаснет сама, не показывается больше одного раза за время
  жизни карточки

### Onboarding
- Интерактивный gesture-gated тур из 8 шагов при первом запуске: первые 5
  продвигаются только реальным действием пользователя, последние 3 —
  информационные (Passcode, Desktop Overlay, Spotlight)
- Подтверждение при пропуске тура (alert), "Replay Onboarding" в
  Settings → General и продублировано в системном меню Help
- Собственные статичные/анимированные иллюстрации жестов на каждый шаг

### Desktop Overlay (экспериментально)
- Режим, в котором окно сидит чуть выше иконок рабочего стола вместо
  обычного окна (тумблер в Settings, продублирован в системном меню
  Window)
- ⌥D — вход в Desktop mode; ⌥1–9 — выход обратно в обычный Space
- Реализовано через Carbon `RegisterEventHotKey` (`GlobalHotKeyManager`)
  — работает, даже когда активно другое приложение

### Внешний вид
- Light/Dark/Auto тема (сегментированный пикер в Settings)

### Settings → Shortcuts
- Справочный список шорткатов приложения (Lock Space ⌘L, Focus Card ⌘F,
  Show Desktop ⌥D, Switch Between Spaces ⌥1–9) с названием и кратким
  описанием у каждого — только для просмотра, сами комбинации фиксированы
  и не переназначаются. ⌘Q и Escape-хендлеры не входят (системные
  конвенции), как и встроенный `TextFormattingCommands()`

### Settings → Pro (тизер подписки)
- Новый таб Pro — иконка кастомная (`FlowerShape`, вертушка/цветок из
  Bezier-кривых, в SF Symbols подходящей нет), внутри содержания
  вертушка залита градиентом, а в самом табе показывается уменьшенным
  monochrome template-изображением, чтобы система сама подсвечивала её
  синим при выборе, как остальные табы
- Список из 4 будущих Pro-функций (Tidy Cards, Bring Your Own API Key,
  Unlimited Spaces, Space Collaboration) — у каждой сплошной цвет иконки,
  но цвета идут последовательным градиентом сверху вниз по списку (как в
  Telegram Premium), а не градиентом внутри каждой иконки по отдельности
- Хэдер (градиентный цветочек + "Thoughts Pro" + капсула "Coming later")
  — часть прокручиваемого содержимого; при скролле схлопывается в
  компактную закреплённую строку без иконки (`onScrollGeometryChange`,
  macOS 15+; на более старых системах хэдер просто не схлопывается)
- Функции из списка, которые уже реализованы в коде (Tidy Cards, BYOK для
  ChatGPT/Claude), визуально возвращены в интерфейс, но нефункционально:
  кнопка Tidy Cards в тулбаре канвы открывает Settings → Pro вместо
  тайдинга; в AI-настройках ChatGPT/Claude показаны в пикере провайдера,
  но задизейблены (`hasKey` всегда `false` для обоих на этой сборке),
  кнопка "Add API Key…" видна, но недоступна, со ссылкой "Learn more" на
  таб Pro. Реального Pro-функционала (алгоритм Tidy, Keychain, сетевые
  сервисы) на `develop` как не было, так и нет
- Блок "Free Beta Access" — приглашение написать на почту/в Telegram за
  бесплатным доступом к Pro через TestFlight на время тестирования; ни
  слова про донат/оплату в самом приложении — тема доната обсуждается
  только лично, в переписке (условие легальности по гайдлайну 3.1.1
  App Store)
- Общий механизм `SettingsNavigator` (синглтон с текущим табом Settings)
  — позволяет любому месту в приложении программно переключить окно
  Settings на нужный таб (`SettingsNavigator.shared.selectedTab = .pro`)
- Фикс: в справочный список Settings → Shortcuts возвращена потерянная
  при разводе Free/Pro строка Focus Card (⌘F) — бесплатная функция

### Окно и фон
- Полупрозрачный `.behindWindow` блюр (в цвет обоев) с фиксом пропадания
  при переходах между Spaces/Mission Control
- Двойное нажатие Cmd+Q для выхода — HUD-баннер
- Безрамочное окно (`hiddenTitleBar`) с собственной зоной драга
- Cmd+N (New Window) полностью отключён — `CommandGroup(replacing:
  .newItem)`, иначе SwiftUI сам добавлял системный пункт "New Window",
  наслаивающий второе окно поверх первого (приложение однооконное)
