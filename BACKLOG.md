### Доска и карточки
- Канва с созданием карточки перетаскиванием; размер квантован шагом 60pt
  с зазором 16pt (`BoardViewModel.snap`/`cardSizeStep`/`cardGap`) — колонка
  из нескольких карточек всегда точно совпадает по краю с одной крупной
  карточкой той же "тайловости"
- Драг/ресайз карточки с подсказками прилипания к краям/углам канвы и
  превью стыковки к соседним карточкам (edge hints, placement preview)
- Удаление карточки долгим нажатием (радиальный индикатор прогресса)
- Цветные теги (7 цветов) через попап у угла карточки
- Приватность карточки: `none` / `spoiler` (тап открывает, авто-скрытие
  через 5с после клика в сторону) / `lock` (открывается через Touch ID)
- Кастомный редактор на NSTextView (`CardTextView`/`CardNSTextView`):
  - смарт-списки: `"- "` → буллет, `"1. "` → нумерованный список,
    автораспознавание; Enter продолжает/убирает пункт, Backspace убирает
    маркер одним нажатием; курсор/выделение не может зайти внутрь маркера
    (перехват через `setSelectedRange`)
  - разделитель по `---` (3–20 тире), рисуется поверх текста заново на
    каждый кадр от актуального `layoutManager` (`DividerAttachment`)
  - персистентность форматирования (bold и т.п.) — `NSAttributedString`
    сериализуется в `Card.formattingData` параллельно с обычным `text`;
    откатывается к обычной реконструкции, если два поля разошлись
    (например, после AI-действия, заменившего текст целиком)
  - вставка только как plain text (изображения/rich-контент отключены)
  - контекстное меню с AI-подменю (см. AI ниже)
- Tidy Cards (Pro) — детерминированная раскладка без AI: карточки делятся
  на 4 группы по своей четверти канвы, каждая группа стягивается к своему
  углу построчной упаковкой ("shelf packing"); карточки с одинаковым тегом
  всегда собираются в один (доминирующий) угол; внутри угла — сортировка
  по тегу, затем по убыванию площади
- Clear Space — очистка всех карточек текущего Space с подтверждением
  через alert (File-меню и кнопка в тулбаре)
- Постоянный AI-бейдж (иконка sparkle) на карточках, созданных через
  Ask AI/Summarize/Extract, с одноразовой pop-in анимацией "из-под нотча"

### Spaces
- 9 независимых Spaces, переключение через ⌥1–9 (`CommandMenu`), плашка с
  именем сверху канвы — клик открывает инлайн-переименование (лимит 30
  символов)
- Персистентность через `BoardStore` (JSON в Application Support),
  миграция со старого единого `cards.json` в Space 1
- Полностью раздельное состояние по каждому Space — переключение не
  анимируется общим кросс-фейдом: только уход старых карточек анимируется,
  новые появляются сразу

### Spotlight
- Индексация карточек в системный Spotlight (кроме карточек в spoiler/lock
  ИЛИ в защищённом Space — см. Security), полная переиндексация на каждое
  сохранение (без diff-логики — карточек мало)
- Переход по результату поиска — активация приложения, переключение на
  нужный Space, подсветка карточки — через
  `NSApplicationDelegate.application(_:continue:restorationHandler:)`,
  так как `.onContinueUserActivity` на SwiftUI-View для уже запущенного
  macOS-приложения ненадёжен
- `saveGeometry()` (чистое перемещение/ресайз) не триггерит переиндексацию
  — только `saveImmediately()` (текст/приватность/имя Space могли измениться)

### Security / Space Lock
- Мастер-тумблер "Passcode" (как в Telegram): выключен по умолчанию;
  включение сразу запускает Create/Confirm passcode flow, тумблер
  становится "включён" только после реального создания кода
- Passcode = 4 физические клавиши (`NSEvent.keyCode`, не символа) через
  `KeyCodeCaptureView` — не зависит от раскладки клавиатуры; хранится в
  Keychain (`PasscodeStore`), никогда в UserDefaults/plaintext
- Touch ID — необязательная надстройка поверх passcode (не альтернативный
  метод): включается только после реального успешного прохождения Touch ID
  один раз; на экране блокировки код-пароль показывается всегда, кнопка
  Touch ID — только если включена
- `Workspace.isProtected` (персистентно) отделено от runtime-набора
  `unlockedProtectedSlots` (никогда не персистится) — после рестарта любой
  защищённый Space стартует заблокированным, даже если был разблокирован
  до выхода
- Cmd+L — мгновенно защищает и блокирует активный Space; no-op если
  мастер-тумблер выключен или Space уже заблокирован
- "Manage Space Locks" в Security-настройках — список всех Spaces с
  переключателем защиты у каждого; выключение защиты (как и выключение
  мастер-тумблера целиком) требует повторного ввода passcode/Touch ID
- Idle auto-lock с настраиваемым интервалом (Only when use ⌘L / 30s / 1 /
  5 / 10 / 30 мин / 1 час) — отдельный `Task` на каждый разблокированный
  защищённый Space (тот же паттерн, что `scheduleDebouncedSave`),
  сбрасывается централизованным `NSEvent`-монитором в `AppDelegate`
  (клик, драг, ввод текста, скролл, движение мыши)
- Settings полностью недоступны, пока активный Space заблокирован
  (заглушка вместо реального содержимого окна — не полагается на
  `.disabled()` у пункта меню, это ненадёжно)
- Заблокированный Space физически выгружает карточки и canvas (не просто
  оверлей поверх) — тот же принцип, что при обычном переключении Spaces
- Экран блокировки переиспользует `StarFieldCanvas` — тот же визуальный
  язык, что у per-card Spoiler/Lock

### AI (BYOK, Pro)
- 3 провайдера: ChatGPT (OpenAI), Claude (Anthropic), Apple Intelligence
  (on-device через FoundationModels, macOS 26+, без ключа)
- Ключ (Keychain) и модель (UserDefaults) хранятся независимо для каждого
  провайдера — переключение туда-обратно не теряет ранее введённый ключ
- Карточные AI-действия (правый клик → подменю AI): Summarize, Rewrite,
  Continue Writing (дописывает, не заменяет), Fix Grammar — каждое со
  своим системным промптом
- Ask AI для всего Space (иконка sparkle в тулбаре) — свободный вопрос с
  контекстом из всех непубличных карточек; там же Summarize Space и
  Extract Action Items
- Общее правило форматирования во всех промптах — без Markdown (карточки
  это plain text, `**`/`#`/backticks иначе попадали бы в текст буквально)
- Результат Space-уровня всегда создаёт новую карточку (с pop-in
  анимацией из-под нотча и постоянным AI-бейджем); результат карточного
  действия правит карточку на месте
- Настраиваемая клавиша отправки в поле Ask AI (Return сразу / Shift+Return
  сразу) — кастомный NSTextView, чтобы перехватывать Return/Shift+Return
  раздельно (SwiftUI TextEditor этого не умеет)
- Индикаторы загрузки и алерты ошибок отдельно для карточного и
  Space-уровня AI

### Focus Card (Cmd+F)
- Cmd+F центрирует карточку с текстовым фокусом в фиксированном размере
  640×480, остальные карточки гаснут и перестают кликаться, холст
  затемняется. Пункт "Focus Card" — в том же меню, что Lock Space/Show
  Desktop; no-op при заблокированном Space, в Desktop mode и во время
  онбординга
- `card.position`/`card.size` не меняются — фокус это чисто состояние
  отображения в `ContentView`, ничего не персистится
- Выход: Cmd+F повторно, Escape (перехватывается в
  `CardNSTextView.cancelOperation` — NSTextView не пропускает его дальше
  сам), клик по затемнённому фону, смена Space. Подсказка про выход
  появляется над карточкой через 3 секунды
- В фокусе скрыты точка тега, AI-бейдж, кнопка удаления, ресайз-хендл и
  зона перетаскивания, а также верхняя капсула Space
- Все скрытия/возвраты завязаны на `focusTransitionCardID` из
  `ContentView.setFocusedCard` — он меняется в том же обновлении, что и
  сам фокус, иначе контролы успевают проехать вместе с карточкой. Текст
  карточки на время перехода гаснет: NSTextView переверстывается на
  каждом кадре анимации ширины, и это видно
- Панель Ask AI под карточкой: свободный запрос про эту карточку (свой
  системный промпт `AICardPrompt`, случайная подсказка-пример в пустом
  поле), ответ показывается под вопросом с разделителем и тремя
  действиями — Insert Below, Replace, Ask Again. Фиксированные
  AI-действия остались в контекстном меню текста, в панели их нет

### Onboarding
- Интерактивный gesture-gated тур из 8 шагов при первом запуске: первые 5
  продвигаются только реальным действием пользователя (создать карточку,
  подвинуть/изменить размер, поставить тег, включить Spoiler, переключить
  Space), последние 3 — информационные (Passcode, Desktop Overlay,
  Spotlight)
- Подтверждение при пропуске тура (alert), "Replay Onboarding" в
  Settings → General в любой момент
- Собственные статичные/анимированные иллюстрации жестов на каждый шаг

### Desktop Overlay (экспериментально)
- Режим, в котором окно сидит чуть выше иконок рабочего стола вместо
  обычного окна (тумблер в Settings)
- ⌥D — вход в Desktop mode (окно уходит НИЖЕ иконок стола, игнорирует
  события мыши, карточки скрыты, фон полностью прозрачный); ⌥1–9 — выход
  обратно в обычный Space
- Реализовано через Carbon `RegisterEventHotKey` (`GlobalHotKeyManager`) —
  работает, даже когда активно другое приложение (напр. Finder после
  клика по иконке стола), не требует разрешения Input Monitoring
- Корректная обработка конфликта с нативным fullscreen (сначала выход из
  fullscreen, потом применение оверлейного уровня/фрейма окна)
- `allowWindowToBecomeKey` — подмена `canBecomeKey`/`canBecomeMain` через
  Objective-C рантайм, иначе в Desktop mode невозможен ввод текста
  (безрамочное окно без `.titled` не может стать key window)
- Увеличенный верхний отступ в Desktop mode (высота выреза + 50pt), чтобы
  карточки не создавались под камерой/системными виджетами стола
